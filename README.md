# Simple-Calculator

A simple scientific calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic: +, -, ×, ÷, %
- Scientific functions: sin, cos, sqrt, ln, log10, pow, abs
- Degrees / Radians toggle
- Operation history stored in localStorage (click history items to reuse)
- Keyboard shortcuts for common actions and functions

## Files

- `index.html` — main page you open in your browser
- `styles.css` — styling for the UI
- `script.js` — JavaScript logic and evaluation code

## How to run locally

1. Download or clone the repository.
2. Open `index.html` in your web browser (double-click the file or right-click → Open With → your browser).
   - No build steps or installations are required for this simple static site.

## How to add these files using the GitHub web UI

1. Go to the repository page on GitHub.
2. Click **Add file → Create new file**.
3. Name the file `index.html`, paste the HTML content, add a commit message, and click **Commit new file**.
4. Repeat to add `styles.css` and `script.js`.
5. (Optional) Enable GitHub Pages under Settings → Pages to host the calculator at `https://<your-username>.github.io/<repo-name>/`.
